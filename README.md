# Rajkumar Malviya — Portfolio

Personal portfolio site. Built with **Next.js 15 (App Router)**, **TypeScript**, **TailwindCSS** and **Framer Motion**. Statically exported and hosted on **GitHub Pages**.

🔗 Live: https://rajkumarmalviya.github.io/rajkumar-malviya-portfolio/

## Develop

```bash
npm install
npm run dev
```

## Build (static export)

```bash
npm run build
# output in ./out
```

## Deploy

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the static export and publishes it to GitHub Pages.

In the repo: **Settings → Pages → Source: GitHub Actions**.
